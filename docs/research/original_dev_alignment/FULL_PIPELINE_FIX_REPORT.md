## 正式执行链审计

| 检查范围 | 门禁或产物 |
| --- | --- |
| 1–3 审批、F0 投影、D0 权重 | 核对 Stage A 回执、预算锁和 D0 运行证据的 SHA-256，复核 F0 Train/Dev 投影与历史带标签顺序。核验 D0 每轮及 U* 权重来源、类型、位置和 SHA，验证 Best 张量与官方选择文件一致，训练前重放该权重并严格比较 Dev 证据。 |
| 4–8 初始化、步数和固定权重 | LS epsilon=0.1，原 seed100、AdamW、模型选择规则及 Train 批次 tape；训练循环仍比对每轮 RNG。验证 30 轮每轮 7 步，第 90 步是 E13 第 6 批且轮未结束。平均使用 E21/E24/E27/E30 原 FP32 权重。 |
| 9–12 统一评价和概率指标 | 每个端点用同一个 Dev evaluator，逐条比对 980 条 ID、对话、标签和顺序。比较 Accuracy、W-F1、Macro-F1、UAR，导出硬标签 NLL、ECE10、Brier、逐类及错误检测 ROC/PR、tie-aware Risk–Coverage。 |

| 19–23 图形、摘要和归档 | Agg 首先自测 CSV/PNG/SVG；正式子进程输出成对的 PNG/SVG 及图索引。生成 `RESULTS.md`、`SHA256SUMS.txt`、归档和末态回执，校验成员、归档 SHA256 与逐文件哈希。D3 缺失时原锁标记 UNAVAILABLE 并报告六个可评价端点。 |
