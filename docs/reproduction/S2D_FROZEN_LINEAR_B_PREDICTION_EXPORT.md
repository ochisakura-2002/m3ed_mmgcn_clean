## 冻结资产与 inference contract

后续 Ubuntu 在 S2D worktree 根目录使用相对路径：

- Bank: outputs/20261107/s2d_q1_feature_bank/analysis/seed100_epoch7_uniform16_v1
- Run: outputs/20261107/s2d_q1_probe/analysis/epoch7_q1_five_seeds_v1/03_linear/b/seed100
- Checkpoint: run 内 best_model.pt，纯 LinearProbe state_dict。
- Dev reference: run 内 predictions_dev.csv，保持原文件只读。
- Normalization: 由 run/config.json 的 normalization 引用与 normalization_identity
  定位并校验，即 archive 内 00_provenance/normalization/b.json。
  不是相对 seed run 目录拼接，也不重新拟合或从 bank 估计统计量。

要求已完成的 Q1 archive；仅验证所需的六个显式 artifact 及 complete.json，
不枚举 archive/bank，也不读取其他 seed、TCN 或 Test。
逐项验证 archive inventory 的 SHA256/size、config normalization identity、
bank_reference 的 metadata/shard identities、normalization 的 Train index identity。

复用原 FeatureBank.values(..., pooled=True)、LinearProbe 和 run_probes.evaluate：
先逐 shard mean_t(B)，再用冻结 mean/std affine transform，Linear(768,6)，softmax。
该路径与原 Q1 Linear-B 完全相同，无 hidden layer。归一化要求 fit_split=train，
axes=[utterance,slot]，count=4818*16，population ddof=0，epsilon=1e-6。
加载 checkpoint 使用 torch.load(weights_only=True) 和 load_state_dict(strict=True)。

默认设备、batch size、CPU threads 取已归档 Q1 记录；--device cpu|cuda 可显式指定，
CUDA 不可用即失败，不自动切换。跨设备/软件版本的误差也必须通过相同 Dev gate，
不放宽 tolerance。

## Dev gate、输出与方法学边界

生产 row count 固定：Train=4818，Dev=978。先在内存中推理 Dev，要求 reference
schema、row count、逐行 utterance_id/order、true_label、pred_label 精确一致。
两边概率都须 finite、nonnegative、sum-to-one（绝对误差 <=1e-6），再要求
max_abs_probability_difference <=1e-6。报告实际最大误差。任何失败均抛错中止，
不运行 Train inference、不创建正式输出目录。

Train 保留 bank index 顺序，后续消费仍按 exact utterance_id join。
输出为 predictions_train.csv（Dev 模式为 predictions_dev.csv），字段固定：
utterance_id,true_label,pred_label,prob_0,prob_1,prob_2,prob_3,prob_4,prob_5。

prediction_export_manifest.json 最后发布，记录 schema/split/rows、Linear-B/seed100、
representation、checkpoint/normalization 路径与 SHA256、bank identity、Git commit、
runtime、Dev reference SHA256、Dev gate 状态/误差和 test_access=false。
仅有 CSV、没有 manifest 的目录不能当成成功结果。已有输出目录一律拒绝；
输出与 bank/Q1 archive 必须互不包含。写出前复查所有只读输入 identity。
单文件复用 Q1 原子的、不覆盖的发布方法。

Train manifest 显式写 in_sample_base_prediction=true：
These Train predictions are generated by the frozen Linear-B seed100 probe that
was itself fitted on the same Train split. They are intended for the low-capacity
exploratory decision-gate experiment and are not claimed to be unbiased
out-of-fold stacking predictions.

该限制明确保留；不做 cross fitting/K-fold 或额外训练。Dev 导出则该字段为 false，
同时保留 Train prediction limitation。后续 dynamic gate 属于另一项
ASYMMETRIC_MERC 任务，本次未实现。

## Fail-closed 与本地验收

CLI argparse choices 和程序入口都在任何 bank/checkpoint IO 前拒绝 test、all、
validation_test 等非 train/dev split。输入/输出路径在 resolve/stat/open 前进行
Test token 检查，resolve 后再检查实际目标路径；拒绝 Test/test_bank/bank_Test/
validation_test/testing-data 等显式命名。bank reader 只消费显式 Train/Dev metadata
和 canonical shards；不构建 Test loader，不枚举 Test bank，不跟随 provenance
中的 source run 或 checkpoint 路径。

Synthetic tests 用临时生成的 7 Train/4 Dev 样本、多 shard、刻意非排序 ID 和预存的
任意 normalization；仅 pytest 进程替换生产 row count，没有 CLI bypass。
覆盖冻结统计复用、数学计算、strict load、schema、duplicate IDs、标签/预测/概率
差异、Test split/path 在 IO 前拒绝、无 discovery/loader、稳定顺序及输入 bytes 不变。
